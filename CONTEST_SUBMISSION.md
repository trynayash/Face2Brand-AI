# Face2BrandAI – Google Cloud Community Day 2025 New Delhi Submission

## Project Description
Face2BrandAI is a SaaS web app that empowers anyone to generate a full personal brand kit using AI and Google Cloud Vision. Upload a selfie, describe your vibe, and get a creative, ready-to-use brand kit in minutes.
